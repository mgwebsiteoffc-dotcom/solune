The imported version provides the standard Shopify theme directory structure, sections, section groups, JSON templates, settings, and a Theme Check workflow. It has been adapted into an original skincare theme. Keep the upstream license with this repository and review all third-party asset/font licenses before publishing.

The currently published Shopify Theme Store requirements still require Online Store 2.0 section support and JSON templates. Shopify's newer block-first Skeleton release candidate omits those structures, so this project uses the official v1.0.0 tag as its starting point. Re-check Shopify's requirements and Skeleton guidance immediately before submission.
