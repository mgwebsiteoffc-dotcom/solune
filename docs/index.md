# Build a considered skincare storefront

Solune is an original Shopify Online Store 2.0 theme designed for skincare brands. This site is a pre-release merchant guide—not a Theme Store listing or a guarantee of Shopify approval.

<div class="callout">
  <strong>Start with the right preview.</strong> Customize and save the unpublished Solune theme you intend to test, then open that same theme's Preview. Changes to an unpublished theme do not update the live published storefront.
</div>

## Quick start

1. Add real products, variants, prices, inventory, product media, and collections in Shopify Admin.
2. Open the Solune preview theme in **Online Store → Themes → Customize** and select the style, colors, typography, navigation, and homepage sections for the brand.
3. Add accurate product content and optional product-information blocks. Use the [product data guide]({{ '/merchant-guide/' | relative_url }}) for metafields, variants, cart options, and content setup.
4. Replace demo imagery and sample copy with licensed brand media and merchant-approved facts.
5. Test shopping flows, keyboard access, mobile layouts, and performance in an authenticated development store before publication.

## Before launch

The theme still needs live Shopify development-store testing, Theme Editor QA, accessibility and Lighthouse review, confirmed support details, licensed demo-store content, and Shopify Theme Store review. Do not treat static validation as proof of storefront quality or approval.
